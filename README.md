# Voxel Strike — папка проекта

```
voxel_strike/
├─ index.html            ← сама игра (один файл)
├─ start.bat             ← запуск через локальный сервер (Windows)
├─ start.sh              ← то же для Mac/Linux
├─ prompts_hunyuan.md    ← промпты для генерации моделей
├─ assets/
│  ├─ models/            ← сюда класть GLB: soldier.glb, awp.glb, arms.glb
│  └─ reference/         ← референсные картинки для Hunyuan
└─ backups/              ← копии предыдущих версий игры
```

## Как запускать
Просто игра (без своих моделей): двойной клик по `index.html`.

Когда появятся модели в `assets/models/`: запускайте через `start.bat`.
Причина: браузер запрещает странице, открытой двойным кликом (file://),
читать соседние файлы, поэтому GLB оттуда не загрузятся. `start.bat` поднимает
локальный сервер (нужен установленный Python) и сам открывает http://localhost:8000.

## Что дальше
Положите soldier.glb / awp.glb в assets/models и напишите в чат, какие файлы
и как называются, я подключу их в index.html (с запасным блочным видом, если файла нет).

## Персонаж (солдат со скелетом)
- `assets/models/soldier.glb` — риггед-модель: 17 костей, клипы `idle, aim_idle, walk, aim_walk, run, aim_run, die`.
- `assets/models/soldier_glb.js` — тот же GLB в base64, чтобы игра работала по двойному клику без сервера.
- `tools/` — как всё собрано из исходной модели: `prep_mesh.py` (упрощение 500k → 20k треугольников, цвет из текстуры в вершины),
  `rig.py` (скелет, веса, IK-руки с винтовкой, анимации), `build_glb.py` (запись GLB).
  Пересборка: `python prep_mesh.py <исходный.glb> soldier_lo.npz 20000`, затем `python build_glb.py`.
- Если GLB не загрузился, боты автоматически рисуются старыми блочными моделями.

## Оружие и руки от первого лица
Всё собрано из кубиков прямо в `index.html` (`buildViewmodels`): у каждого оружия 55–90 деталей, руки камуфляжные и толстые, на двухзвенном IK.
Анимации — в `updateViewmodel`: бег, стрейф, посадка, смена оружия, отдача, отдельные перезарядки (магазин, дробовик по патрону, затвор снайперки, ракета), рубящий удар ножом.
Пробные GLB-версии рук и AWP лежат в `backups/glb_experiments/` — игра их не использует.

## Игра с телефона
Определяется автоматически (сенсорный экран без мыши); принудительно — `index.html?touch=1`. Нужна альбомная ориентация: в портретной показывается предупреждение «Переверните телефон», игра ставится на паузу.
- Левый джойстик (плавающий): ходьба, до упора — бег; наклон аналоговый.
- Свайп по правой части экрана — обзор; палец можно вести прямо с кнопки ОГОНЬ.
- Кнопки: ОГОНЬ справа и ещё одна ОГОНЬ слева сверху (играть можно тремя пальцами: джойстик, обзор, огонь), ЦЕЛЬ (нажал — включил, ещё раз — выключил), ▲ прыжок, ↻ перезарядка, граната, подкат, смена оружия, Блоки (режим строительства, там ЦЕЛЬ ставит блок), Счёт, II (пауза). В режиме гарпунов ЦЕЛЬ становится «Крюк 1», добавляется «Крюк 2».
- Лёгкий автоприцел: при прицеливании или стрельбе камера слегка подтягивается к видимому врагу в узком конусе (около 4°), рядом с целью обзор чуть замедляется. Код — `aimAssist()` в index.html.
- Оружие переключается тапом по значкам внизу. При запуске включается полноэкранный режим и фиксируется альбомная ориентация (где браузер позволяет).
- Дальность прорисовки на телефоне по умолчанию 4, разрешение рендера без повышения (для скорости).
- `?debug=1` открывает объект `window.__vs` для автотестов.

## Установка как приложение (PWA)
Игру можно установить на телефон/ПК — она откроется на весь экран без панелей браузера, в альбомной ориентации, и будет запускаться офлайн (кроме игры по сети).
- Android (Chrome): в меню игры кнопка «Установить как приложение» или меню ⋮ → «Установить приложение».
- iPhone (Safari): «Поделиться» → «На экран „Домой“».
- Файлы: `manifest.json`, `sw.js` (service worker), `icons/` (иконки; пересборка — `python tools/make_icons.py`).
- Обновления игры доходят автоматически: свои файлы всегда берутся с сервера, а кэш нужен только когда сети нет. `VERSION` в `sw.js` менять не нужно — только если хотите принудительно сбросить кэш (например, сменили версию three.js).

## Режимы и снаряжение
- В меню три режима: **команды с ботами**, **FFA с ботами** и **сетевая 1 на 1**. В сетевой игре хост в самом начале выбирает **Стандарт** или **Ноу-скоп + крюки**; присоединившийся получает режим хоста.
- Код подключения теперь компактный (`VS1-…`, ~300 символов, раньше несколько тысяч — мессенджеры его обрезали, на телефоне выходило «неверный код»). Есть кнопки «Копировать», «Поделиться» и «Вставить из буфера». Для NAT добавлены STUN и публичный бесплатный TURN (openrelay.metered.ca) — это сторонний сервис, при желании замените `RTC_CFG` в index.html.
- **Снаряжение**: три слота — основное, запасное, нож. По умолчанию автомат, пистолет, нож. Остальное оружие открывается с уровнем и выбирается в меню («Снаряжение») и на паузе; набор запоминается. В ноу-скоп режиме доступна только снайперка.
- Автоподъём: ступеньки высотой в 1 блок берутся без прыжка.
- Враги чуть красноватые и с тонкой красной обводкой, свои — холодного оттенка (`Soldier.tint`, `Soldier.outlineMat`). Направления обводки лежат в атрибуте NORMAL модели (`tools/build_glb.py`).
- Временно выключены рывок, батут и осмотр оружия: флаги в `FEATURE` (index.html), кнопки скрыты. Чтобы вернуть — `true` в `FEATURE` и убрать `#tDash,#tPad,#tInsp{display:none}` в стилях.
- Из паузы и с экрана конца матча можно выйти в главное меню («Выйти в меню» / «В меню»). В сетевом матче перед выходом спрашивается подтверждение, а у соперника появится «Соединение потеряно».
